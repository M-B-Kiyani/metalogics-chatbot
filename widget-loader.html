Chatbot Widget Integration

Copy and paste the code below before the closing </body> tag of your website.

Important: Replace the URL placeholders with your actual Railway service URLs and your specific Widget API Key.

Integration Code:

<!-- Metalogics Chatbot Widget -->
<script 
  src="https://YOUR-WIDGET-SERVICE-URL.up.railway.app/metalogics-chatbot.iife.js"
  data-api-key="YOUR_WIDGET_API_KEY"
  data-api-url="https://YOUR-BACKEND-SERVICE-URL.up.railway.app"
  data-brand-color="#2563eb"
  data-position="bottom-right"
  defer
></script>
